# Nemetrix Device (Bedrock Addon)

A Minecraft **Bedrock** addon inspired by the **Nemetrix** from *Ben 10*. It turns your **tame pet dog** into genetic predators from the Nemetrix, and you must **manually select** which predator form your dog takes.

## Features

- **Nemetrix Device item** — a handheld device you can use at any time.
- **Manual form selection** — using the device opens a UI dialog where you pick exactly which predator your dog transforms into (of the 5 available forms).
- **5 predator forms**, each the natural predator of a Ben 10 alien:
  - **Tyrannopede** — predator of Wildmutt (centipede-like, fast, climbs).
  - **Mucilator** — predator of Stinkfly (armoured, tanky slug).
  - **Hypnotick** — predator of Ditto (floating jellyfish).
  - **Crabdozer** — predator of Four Arms (heavy hitter crab).
  - **Terroranchula** — predator of Spidermonkey (giant spider).
- **Follows you** — the transformed predator stays loyal and follows its owner, just like the dog did.
- **Revert at will** — use the device again near the transformed predator to turn it back into your dog. The dog's custom name and ownership are preserved.
- Each predator has distinct stats (health, damage, speed, movement style).

## Pack structure

```
nemetrix_bp/      Behavior pack (item, entities, scripting)
nemetrix_rp/      Resource pack (models/textures, client entity defs)
```

## Requirements

- Minecraft **Bedrock** (the latest stable release is supported).
- **Experimental / Beta APIs:** enabling the "Beta APIs" toggle, **"Holiday Creator Features"** and **"Custom Biomes"** in the world settings is required for the custom item + scripting + custom entities.

## Install (world / packs folder)

1. Zip each pack folder (the `nemetrix_bp` folder and the `nemetrix_rp` folder) separately into `.mcpack` files, OR copy the two folders into your world's `behavior_packs/` and `resource_packs/` directories.
2. In Minecraft, open your world's **Settings → Behavior Packs** and **Resource Packs** and activate both packs.
3. Enable the required experimental toggles mentioned above.
4. Join the world. The Nemetrix item can be obtained with:
   ```
   /give @s nem:nemetrix
   ```

> For a quick `.mcaddon`, zip `nemetrix_bp` and `nemetrix_rp` **together** (as two folders inside one zip) and rename the file to `.mcaddon`.

## How to use

1. Tame a wolf with bones (in your world) so it becomes your dog.
2. Stand within **5 blocks** of your tame dog and **use** the Nemetrix device.
3. A dialog appears: pick one of the 5 predator forms (or cancel).
4. Your dog transforms into that predator and follows you.
5. To change form, revert first: stand near the transformed predator and use the Nemetrix again — it turns back into your dog. Then pick a new form.

## Scripting / API notes

- Uses `@minecraft/server` and `@minecraft/server-ui`.
- Item use is intercepted in `world.beforeEvents.itemUse` (cancelled so the item is never consumed).
- The transformation keeps track of the original dog (custom name + owner) via `setDynamicProperty`/`getDynamicProperty` and restores them on revert.

## Textures

Only text files can be generated by this project — it cannot produce binary PNG images. To keep the addon working **with zero custom PNGs**, the predators reuse **existing vanilla Minecraft textures** (spider / cave spider / slime / snow golem), so they render on any Bedrock client with nothing extra to add.

The **only** image you must still supply is the Nemetrix item icon:

- `nemetrix_rp/textures/items/nemetrix.png` — the Nemetrix device icon (32×32 recommended). The folder and JSON reference (`textures/items/nemetrix`) are already in place; drop a PNG there.

Optional (nice to have, not required for gameplay):

- Pack icons: `nemetrix_bp/pack_icon.png` and `nemetrix_rp/pack_icon.png` (128×128). Without them the packs just show a default icon in the pack menu.

If you later want fully custom predator skins, replace the vanilla texture path in each `nemetrix_rp/entity/<name>.entity.json` `textures.default` with your own `textures/entity/<name>` PNG.

Current predator → vanilla texture mapping:

| Predator | Geometry | Texture used |
|----------|----------|--------------|
| Tyrannopede | spider | `textures/entity/spider/spider` |
| Mucilator | snow golem | `textures/entity/snow_golem` |
| Hypnotick | slime | `textures/entity/slime/slime` |
| Crabdozer | spider | `textures/entity/spider/cave_spider` |
| Terroranchula | spider | `textures/entity/spider/spider` |

## Troubleshooting

- **Item doesn't show a texture** → add `nemetrix_rp/textures/items/nemetrix.png` (see above).
- **No dialog opens** → make sure Beta APIs and Holiday Creator Features are enabled, and you are within 5 blocks of a *tame* wolf; only wolves owned by you count.
- **Predator looks wrong** → replace the vanilla texture path in the corresponding `nemetrix_rp/entity/<name>.entity.json` with your own PNG.

## Build/package

There is no compilation step for Bedrock addons. Just zip the packs (see "Install" above) and drop them into the world.
